Mayo Run – Personvernerklæring

Sist oppdatert: August 2026

Mayo Run samler ikke inn eller lagrer personopplysninger hos utvikleren. Spillprogresjon og kjøpsvalg lagres lokalt på enheten din.

Datainnsamling

  • Appen sender ingen persondata til utvikleren.
  • Highscore, valgt figur og kosmetikk lagres lokalt på enheten (UserDefaults).

Kjøp i appen

Mayo Run har engangskjøp av figurer, skins og bakgrunner. Alle kjøp håndteres av Apple via App Store (StoreKit) — vi mottar eller lagrer aldri betalingsopplysningene dine. Apples behandling av kjøpsdata dekkes av Apples egen personvernerklæring.

Game Center

Hvis du er logget inn på Game Center, sendes poengsummen din til en global resultatliste. Dette er en Apple-tjeneste, og din Game Center-profil og score håndteres av Apple etter deres personvernvilkår. Du kan la være å bruke Game Center ved å logge av tjenesten i iOS-innstillingene.

Analyse og sporing

Mayo Run bruker ikke analyseverktøy, sporing eller annonser.

Tredjepartstjenester

Utover Apple (App Store / StoreKit for kjøp og Game Center for resultatlisten) bruker appen ingen tredjepartstjenester, og den har ingen annonse- eller analyse-SDK-er.

Barns personvern

Mayo Run er trygt for brukere av alle aldre og inneholder ikke noe innhold som krever ekstra personvernhensyn.
